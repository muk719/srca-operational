# الملف التشغيلي — هيئة الهلال الأحمر السعودي (فرع تبوك)

نظام ويب لإدخال ومتابعة التقارير اليومية للأقسام الاثني عشر، مع لوحة أدمن وعرض تقديمي للاجتماع التشغيلي.

## التقنية
- PHP 8.2 + Apache (عبر Dockerfile)
- MySQL
- الاستضافة: Railway — النشر تلقائي من هذا الريبو

## الدخول
- صفحة الدخول: `operational_login.php`
- الأدمن → لوحة التقارير (`operational_file.php`) + العرض التقديمي (`operational_presentation.php`)
- كل قسم → صفحته `dept_*.php`

## قاعدة البيانات
- المخطط: `operational_management_hosting.sql`
- الاتصال: `db.php` (يقرأ متغيرات البيئة MYSQL* على Railway تلقائياً)
